Book Data Analysis 📚

Project Overview

This project focuses on analyzing book data using Python.

Objectives

- Explore and understand book data.
- Perform data analysis using Python.
- Identify patterns and insights from the dataset.
- Visualize data to understand trends.

Tools Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib

Project File

- "Book_Data_Analysis.ipynb" – Jupyter Notebook containing the data analysis.

- ## Key Findings
- Total books analyzed: 999 (no missing values)
- Average book price: £35.07
- Price range: £10.00 (cheapest) to £59.99 (most expensive)
- Prices are spread fairly evenly across the £10 to £60 range
- Ratings (1 to 5 stars) are almost evenly distributed, with roughly 180 to 230 books per rating
- All books in the dataset are in stock
